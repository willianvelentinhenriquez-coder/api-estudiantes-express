# 🚀 API REST de Administración de Estudiantes - Express.js

Proyecto desarrollado como parte de la actividad evaluada para el módulo Backend con Node.js en Kodigo. Consiste en la construcción de un servidor **Express.js** que provee una API REST completa para gestionar un listado de estudiantes almacenado en memoria (array de objetos).

---

## 🛠️ Tecnologías Utilizadas

- **Node.js** (Entorno de ejecución backend)
- **Express.js** (Framework de servidor web)
- **JavaScript ES6+**
- **npm** (Gestor de paquetes)

---
